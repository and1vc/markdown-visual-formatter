# Markdown Visual Formatter

A Visual Studio Code extension that provides a simple formatting toolbar for Markdown cells in Jupyter notebooks (`.ipynb`).

## Features

- **Highlight Text:** Highlight selected text using Markdown-compatible HTML.
- **Text Color:** Change the color of selected text using a color palette.
- **Background Color:** Apply background colors to selected text.
- **Clear Formatting:** Remove formatting applied by the extension while preserving the text content.

## Requirements

- Visual Studio Code 1.144.0 or later.
- Jupyter notebooks (`.ipynb`) with Markdown cells.

## Usage

1. Open a Jupyter notebook in Visual Studio Code.
2. Select text inside a Markdown cell.
3. Use the formatting buttons in the cell toolbar.
4. Choose a color from the palette or clear the applied formatting.

## Development

To compile the extension locally:

```bash
npm install
npm run compile
```  

To launch the Extension Development Host, press `F5` in Visual Studio Code.
